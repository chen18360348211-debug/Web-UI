运行预览：

```powershell
node scripts/serve.mjs
```

打开 http://localhost:4173/ 。无需安装依赖。可直接交付或托管 `dist/` 目录。

GitHub Pages 使用 `.github/workflows/pages.yml` 发布 `dist/`：在仓库 Settings → Pages 中选择 GitHub Actions，推送 `main` 或 `codex/publish-site` 分支后自动验证倒计时并部署。全部图片、字体与视频使用本地相对路径，支持仓库子目录网址；无需额外的服务器或数据库。

- `dist/index.html`：完整静态页面，文字为 HTML。
- `dist/styles.css`：普通 CSS，保留 Figma 图层 ID 便于逐项核对。
- `dist/assets/figma/`：原始 Figma 图片、SVG、悬停按钮及闯关白底素材。
- `dist/fonts.css`、`dist/assets/fonts/`：本地字体和许可。
- `source/figma/`：已替换为本地素材路径的 Figma 板块参考。
- `scripts/build_page.py`、`scripts/figma_css.py`：将参考转换为静态页面；可在 Python 3 环境运行 `python scripts/build_page.py`。
- `scripts/text-dimensions.json`：Figma 原始文字容器尺寸。
- `design-qa.md`：视觉与浏览器验证记录。

页面随 PC 浏览器宽度等比缩放。倒计时已启用，每秒按真实时钟重算，截止于 **2026 年 11 月 30 日 23:59:59（America/New_York，美国东部时间）**，即 `2026-12-01T04:59:59Z`；到期显示全零，刷新和标签页恢复时重新校时。日期配置在 `dist/countdown-core.mjs`。浏览器支持原生 Temporal 时直接使用，否则按需加载本地固定版本兼容文件。

活动导航的选中按钮和未选中按钮分别使用 Figma 对应的悬停物料，保持原有尺寸。当前页面交互包括配件多选、板块定位和下述动效；购买及表单提交保持静态，页面为 PC 布局。

内页活动导航滚动至窗口顶部后使用原生 CSS sticky 保持吸顶，向上回到原位置恢复；吸顶出现和隐藏采用上下滑动过渡。标题缩放区或主推产品画面进入视口时上滑隐藏，两者完全离开后下滑恢复；减少动态效果时直接切换状态。保持原有 1920×80 尺寸，不增加页面高度，透明轨道不拦截下方交互。状态检测使用独立的稳定位置标记，不受主推缩放或导航滑动影响。

放大过程不使用图片透明度补间。图层共用同一容器变换，位移保持线性，旋转和缩放使用起止缓动，并保持原生滚动时间线驱动，避免中心漂移及起止突变。
